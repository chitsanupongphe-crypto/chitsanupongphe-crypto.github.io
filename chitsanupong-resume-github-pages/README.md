# Chitsanupong Resume Website

เว็บไซต์ Resume/Portfolio สำหรับใช้งานกับ GitHub Pages

## ไฟล์หลัก

- `index.html` — เนื้อหาเว็บไซต์
- `style.css` — รูปแบบและ Responsive Design
- `script.js` — เมนูมือถือและ Animation
- `profile.jpg` — ให้ใส่รูปโปรไฟล์ของตัวเองโดยตั้งชื่อไฟล์นี้

## วิธีใช้กับ GitHub Pages

1. เปิด Repository ชื่อ `chitsanupongphe-crypto.github.io`
2. อัปโหลด `index.html`, `style.css`, `script.js` และ `profile.jpg`
3. Commit changes
4. เปิด `https://chitsanupongphe-crypto.github.io/`

## จุดที่ควรแก้

ค้นหาใน `index.html` แล้วแก้:
- `your-email@example.com`
- LinkedIn link
- ชื่อมหาวิทยาลัย
- ลิงก์ VIEW ของแต่ละ Project
- รายละเอียด About / Skills / Project ตามข้อมูลจริง
